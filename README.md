## Sobre o projeto

Aplicação web desenvolvida em React para:

- autenticação de usuários
- gestão de produtos
- registro de vendas
- visualização de dashboard e relatórios

## Tecnologias

- React
- React Router
- JavaScript
- CSS

## Como rodar localmente

1. Instale as dependências:

```bash
npm install
```

2. Inicie o projeto:

```bash
npm start
```

3. Abra no navegador:

`http://localhost:3000`
